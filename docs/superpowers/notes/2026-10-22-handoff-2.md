## Відкладені дрібниці (з рев'ю, не виправлені)

- Паніка в потоці скла валить увесь shell (`panic = "abort"`; зараз захищено інваріантами).
- `glass = false` однаково ховає бар від запису екрана (шар завжди `Backdrop::Glass`).
- Підроблене `WM_APP+4/+6` від іншого процесу того ж користувача може обвалити shell; відкладене повідомлення до знищеного вікна втрачає свій `Box`.
- `WM_ENDSESSION` може бути відкладене → таскбар не відновиться при вимкненні (наступний запуск відновить зі state-файлу).
- Малий запас CPU над відео на ширших моніторах — кешувати карту зміщення лінзи.
- «Capture unavailable» пишеться в журнал на кожен показ бару.
- Радіус капсули — окреме поле конфігу, не прив'язане до висоти.

## Середовище

- `cargo`: `$env:Path="$env:USERPROFILE\.cargo\bin;$env:Path"`; `git`: `C:\Programs\Git\cmd\git.exe`.
- Перед release-збіркою зупиняти NewWin: `Get-Process NewWin | Stop-Process -Force`. Запуск з журналом: `$env:NEWWIN_DEBUG="1"; Start-Process .\target\release\NewWin.exe`; журнал `%LOCALAPPDATA%\NewWin\logs\newwin.log`.
- **Системний годинник може стрибати назад** (було ~2.5 год): cargo тоді не перезбирає змінені файли — робити `cargo clean`.
- Не запускати Screen Snipping за користувача; не тиснути Shut down/Restart/Sign out/Sleep.
- Скляні вікна не видно на знімках DXGI (`crates/ui/examples/screenshot.rs`) — вигляд перевіряє користувач, механіку — журнал і потоки/CPU.
- У PowerShell P/Invoke передавати `[NullString]::Value`; у PS 5.1 не передавати в git аргументи з лапками — повідомлення коміту через файл (`git commit -F`).
