## Живий чекліст (з користувачем)

- [x] Setup: темний, без UAC, одна сторінка з папкою (користувач вибрав `C:\Programs\NewWin`); після «Готово» NewWin працює.
- [x] Встановлення поверх запущеної збірки з `target\release`: вона закрилась, запустився встановлений NewWin; `Run\NewWin` → `"C:\Programs\NewWin\NewWin.exe"`.
- [x] Spotlight знаходить *NewWin Settings*; About показує 1.0.0; у «Встановлених програмах» NewWin 1.0.0 з іконкою-капсулою.
- [x] Оновлення (той самий Setup ще раз, двічі): сторінки з папкою немає, налаштування збереглися, `--quit` 0.22 с.
- [x] Дрібниці M4: автопрокрутка й колесо під час перетягування, плавне Ctrl+↓, каретка в неактивному вікні, *Clear*/*Restore* знімають підтвердження одне одного. Шаблони дати з довільним текстом Windows показує як текст; *Invalid format* — лише для порожнього результату.
- [x] *Restore Windows taskbar*: NewWin і Settings вийшли (`--quit` код 0, 0.23 с), не повернулися.
- [x] Перезавантаження: Windows 15:17:55, NewWin стартував сам о 15:18:51.
- [x] Видалення через «Параметри → Програми»: таскбар Windows на місці; немає папки програми, `%APPDATA%\NewWin`, `%LOCALAPPDATA%\NewWin`, `Run\NewWin`, ярлика, запису в Uninstall, процесів.
- [x] Простій 10 хв — таблиця вище.

## Знайдено під час живої перевірки й виправлено

1. **Spotlight не бачив *NewWin Settings* одразу після встановлення** (`36d538b`): Setup створює ярлик за секунду до запуску NewWin, а AppsFolder показує його із запізненням, і зміна теки приходить до старту стеження. Тепер — одне повторне індексування через 5 с після старту.
2. **Дві «Settings» у Spotlight** (`52a5faf`): системна команда звалася *Settings* поруч із програмою *Settings* Windows, а ярлик *NewWin Settings* її дублював. Команда тепер *NewWin Settings* / «Налаштування NewWin» (ключ історії той самий), ярлик на `NewWinSettings.exe` у Spotlight не показується. «Настройки» в меню бару лишаються — це переклад самого Windows.

## Фінальне рев'ю

Окремий рецензент (opus), уся гілка: 0 критичних. Виправлено в `a60737e`: перше Ctrl+↓ після кліку не анімувалося (застарілий `dropped_offset`); втрата захоплення миші під час перетягування тримала автопрокрутку на 60 fps (тепер `WM_CAPTURECHANGED` завершує натискання поза вікном — як скасування в кнопок Windows); вартовий, що зупинився через подію `Quitting`, не повертав таскбар, якщо `--quit` загинув посередині (тепер повертає з файла стану; перевірено наживо RED→GREEN).

## Рішення, ухвалені під час виконання

1. Inno Setup **7.1.0** (остання стабільна, підпис Pyrsys B.V.) замість 6.7 зі специфікації — з дозволу користувача; встановлено per-user у `%LOCALAPPDATA%\Programs\Inno Setup 7`.
2. Відкладена вада M4 «`autostart_set(false)` не видаляє `REG_EXPAND_SZ`» виявилась неіснуючою: `RegGetValueW` з `RRF_RT_REG_SZ` розгортає такий запис. Тест лишено як запобіжник.
3. Нестабільні тести: `backdrop.rs` — область захоплення була на 4 px ширша за тестове вікно (бачила живі вікна позаду) плюс DWM-згасання попереднього вікна; `tray_seen.rs` — залишені теки попередніх прогонів при повторі pid. Тести тепер прибирають за собою (690 старих тек видалено).
4. `ReorderList::commit` сам анімує клавіатурне переміщення (окремий `commit_step` не потрібен).
5. Збереження незбереженої зміни при закритті Settings уже було (`main.rs` після циклу повідомлень) — окремого тесту не додавали.
6. `view.rs` і `body.rs` розбито на `view/{banner,content,focus,tests}.rs` і `body/{paint,pointer,tests}.rs`.
7. Інструменти Claude бачать застарілу віртуальну копію `%APPDATA%`, `%LOCALAPPDATA%` і HKCU для процесів, які вони не запускали; справжній стан — лише через термінал користувача. Звідси хибна «залишена тека» після першого тихого видалення.

## Відкладено (дрібниці)

- Два одночасні `--quit` бачать одне одного як NewWin і можуть завершити одне одного (Setup тоді покаже «Не вдалося закрити NewWin»; повторний запуск працює).
- *Restore* закриває Settings, навіть коли `NewWin.exe --quit` не вдалося запустити.
- `show_native()` вимикає автоприховування рідного таскбару, якщо файла стану немає, а таскбар схований.
- Специфікація M5 ще згадує Inno Setup 6.7.
