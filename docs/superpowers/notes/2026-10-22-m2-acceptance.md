## Перевірено наживо мною (без користувача)

- Наш `Shell_TrayWnd` перший для `FindWindow`; explorer один раз підняв свій трей вище — хук `EVENT_OBJECT_REORDER` повернув наш на місце.
- Програми реєструють іконки в нас: MSI Afterburner, Discord, Claude, системні іконки explorer («Safely Remove Hardware»). Копії приймає explorer.
- Закріплений режим через наш хост: робоча область починається з 48 px.
- Kill shell → watchdog перезапускає його, іконки знову в нас за ~20 мс.
- `⌃` відкриває трей під баром (вирівняний по лівому краю): NewWin, MSI Afterburner, Safely Remove Hardware, Claude, Discord; набір «s» фільтрує до 3 рядків, віконце зменшується; Esc закриває.
- Клік по динаміку відкриває віконце гучності по центру під ним.
- Мережа: Ethernet, інтернет, 192.168.31.84.
- Клік по розкладці перемикає активне вікно UKR → ENG → UKR, бар показує зміну за 50 мс.
- Win+N відкриває центр сповіщень зі схованим таскбаром (власний календар не потрібен).
- `IPolicyConfig` перемикає пристрій виводу і повертає назад.

Під час роботи монітор спав (його аудіовихід GO27Q24G зник, DXGI не давав кадрів), тому вигляд скла не перевірено, а тести захоплення `crates/ui/tests/backdrop.rs` тимчасово падали; коли монітор прокинувся, увесь набір пройшов: 171 тест, 0 падінь.

## Чекліст для користувача (не перевірено)

- [ ] Вигляд: скло віконець трею й гучності, пігулка, що перетікає, анімація шеврона, підказки.
- [ ] NVIDIA, Telegram, Steam у треї: лівий клік відкриває програму, правий — її меню.
- [ ] Explorer restart (`Stop-Process -Name explorer -Force`): іконки повертаються в трей.
- [ ] Навушники ↔ динаміки з віконця гучності; клавіші гучності рухають слайдер; колесо над динаміком ±2 %; середній клік — mute.
- [ ] Від'єднання Ethernet: іконка «немає мережі» за ~½ с і назад.
- [ ] `ENG` ↔ `UKR` клавішами Alt+Shift і Win+Space.
- [ ] Чи показувати в треї системні іконки explorer (гучність, «Safely Remove Hardware»).
