## Режим роботи з користувачем

Пише українською, делегує технічні рішення, пояснювати просто. Хоче «сексі пексі»: рідке скло, плавно, монохром. **Не вигадувати замінники поведінки рідних програм** (меню, панелі) — робити «як має бути»: справжнє рідне. Просить зупинятись на ~98 % ліміту сесії й ставити все на паузу.

## Середовище й пастки

- `cargo`: `$env:Path="$env:USERPROFILE\.cargo\bin;$env:Path"`. Перед release-збіркою: `Get-Process NewWin | Stop-Process -Force`; повний перезапуск з відновленням таскбару — `NewWin.exe --restore-taskbar`, потім `Start-Process .\target\release\NewWin.exe` (`$env:NEWWIN_DEBUG="1"` для журналу `%LOCALAPPDATA%\NewWin\logs\newwin.log`).
- Відкрити Spotlight для заміру без користувача: `keybd_event(0x5B…)` з PowerShell (нетеговане натискання хук сприймає як справжнє).
- Bash heredoc з `'EOF'` зберігає `\\`, але в `sed`-заміні backslash губиться — код писати через Write/Edit. Python немає.
- Не тиснути Shut down / Restart / Sign out / Sleep; не вбивати explorer без згоди.
