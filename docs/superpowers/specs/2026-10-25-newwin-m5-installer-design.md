# NewWin M5: інсталятор і полірування (доповнення до дизайну)

Дата: 2026-10-25
Статус: погоджено з користувачем, чекає рев'ю специфікації

Доповнює [2026-10-21-newwin-design.md](2026-10-21-newwin-design.md), §3 (процеси, `installer/`), §5 (відновлення таскбару) і §15 п. 5. Закриває відкладені дрібниці з [нотаток приймання M4](../notes/2026-10-23-m4-acceptance.md). Де документи розходяться, діє цей.

## 1. Що погоджено з користувачем

- Мета — готовий продукт: інсталятор плюс полірування відкладених дрібниць.
- **Інсталятор Inno Setup**, «короткий темний»: темний майстер без картинок, одна сторінка з папкою, далі встановлення й «Готово». NewWin запускається сам.
- **Видалення завжди стирає все**, зокрема налаштування й журнали, без запитань.
- Решту технічних рішень користувач делегував.

## 2. Інсталятор

### 2.1. Збірка

- Скрипт `installer/newwin.iss`, Inno Setup **6.7.x** (темний майстер з'явився в 6.6). Компілятор `ISCC.exe` ставиться на машину розробника окремо, у репозиторій не входить.
- `scripts/build-installer.ps1`: зупиняє запущений NewWin так само, як інсталятор (§3), виконує `cargo build --release`, бере версію з `Cargo.toml` і викликає `ISCC.exe /DAppVersion=<версія>`. Результат: `target\installer\NewWin-Setup-<версія>.exe`.
- Версія workspace: **0.1.0 → 1.0.0**. *About* у Settings показує її з `CARGO_PKG_VERSION`.

### 2.2. Поведінка

| Що | Як |
|---|---|
| Права | `PrivilegesRequired=lowest`: без UAC, лише для поточного користувача (NewWin і так працює без підвищення, §12 дизайну) |
| Папка | за замовчуванням `{localappdata}\Programs\NewWin`, можна змінити. Під час оновлення сторінку з папкою пропущено (`DisableDirPage=auto`) |
| Мова | англійська й українська (офіційний `Ukrainian.isl`), вибір за мовою інтерфейсу системи, без діалогу вибору |
| Сторінки | лише папка → встановлення → «Готово». Без вітання, ліцензії, групи меню й сторінки «Ready» |
| Вигляд | `WizardStyle` модерний темний, без бічної та верхньої картинок; іконка Setup — іконка NewWin (§2.3) |
| Файли | `NewWin.exe`, `NewWinSettings.exe`, `LICENSE` |
| Ярлик | `{userprograms}\NewWin Settings.lnk` → `NewWinSettings.exe` (Spotlight індексує меню «Пуск»). Ярлика для `NewWin.exe` немає: він працює завжди |
| Запис у «Встановлених програмах» | назва *NewWin*, версія, іконка `{app}\NewWin.exe` |
| Після встановлення | `NewWin.exe` запускається завжди, без прапорця на сторінці «Готово» (`nowait`). У тихому режимі (`/SILENT`) теж |
| Автозапуск | інсталятор його не пише: shell при старті сам записує `HKCU\…\Run\NewWin` = шлях до встановленого exe, якщо `start_with_windows = true` (так уже працює з M4). Збірка з `target\release`, запущена пізніше, перепише шлях на себе, як і зараз |
| Оновлення | новіший Setup поверх старого: перед копіюванням файлів закриває NewWin (§3), замінює файли й запускає знову. Налаштування не чіпає |
| Restart Manager | `CloseApplications=no`: закриття робить лише наш `--quit`, бо RM не повертає таскбар |

Перед копіюванням файлів (`PrepareToInstall`) інсталятор розпаковує **новий** `NewWin.exe` у `{tmp}` і запускає `{tmp}\NewWin.exe --quit`, чекаючи завершення. Так закривається будь-який запущений NewWin, з будь-якої папки, зокрема й збірка з `target\release`. Якщо `--quit` повернув помилку, встановлення зупиняється з повідомленням «Не вдалося закрити NewWin», і файли не замінено.

### 2.3. Іконка

- Монохромна: білий контур капсули (як бар) на прозорому тлі, без кольору й тексту.
- Один `assets/newwin.ico` з розмірами 16, 20, 24, 32, 40, 48, 64 і 256 px. Генерується скриптом із векторного опису й лежить у репозиторії.
- Вбудовується в `NewWin.exe` і `NewWinSettings.exe` як ресурс (у `build.rs` поруч із маніфестом). Вікна NewWin цю іконку не показують: на барі й у треї всюди лишається текст.

## 3. `NewWin.exe --quit`

Нова роль процесу (`roles.rs`) для інсталятора, деінсталятора й кнопки *Restore Windows taskbar*. Мета: після неї жодного процесу NewWin не лишилося, а рідний таскбар показано.

1. Створює іменовану подію `Local\NewWin.Quitting`. Watchdog перед кожним перезапуском shell перевіряє її: якщо подія існує, він не перезапускає shell, а відновлює таскбар і виходить. Так зникає вада «watchdog перезапускає shell після Restore».
2. Надсилає `WM_APP + 20` вікну `NewWin.Ping` (звичайний Quit: shell повертає таскбар, watchdog бачить вихід із кодом 0 і теж виходить). `WM_CLOSE` отримують вікна `NewWinSettings.exe`.
3. Чекає до **3 с**, поки зникнуть м'ютекси `Local\NewWin.Shell`, `Local\NewWin.Watchdog` і `Local\NewWin.Settings`. Перевіряє раз на 100 мс, і лише під час цього очікування.
4. Що лишилося, завершує примусово: усі процеси `NewWin.exe` і `NewWinSettings.exe` поточного користувача, крім себе. Знайдено через Toolhelp за іменем образу. Повторює до 3 разів, поки нічого не лишиться.
5. Відновлює таскбар з файла стану (`restore_from_state_file`), а за відсутності файла просто показує таскбар. Виконується навіть тоді, коли NewWin не був запущений.
6. Код виходу: 0, якщо процесів не лишилося; 1, якщо лишились (тоді інсталятор зупиняється, §2.2).

`--restore-taskbar` лишається як був (лише крок 5, для тестів). Кнопка *Restore Windows taskbar* у Settings запускає `NewWin.exe --quit` поруч із собою і закривається. Власне 3-секундне очікування в `about.rs` (`RestoreWait`) прибирається.

## 4. Видалення

Порядок у деінсталяторі:
1. `{app}\NewWin.exe --quit` з очікуванням (`[UninstallRun]`, `runhidden`). Помилку не зупиняє: файли однаково видаляються, а Windows відкладе видалення зайнятих до перезавантаження.
2. Видалення файлів програми й ярлика (стандартне).
3. Видалення значення `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\NewWin` (`[Code]`, після видалення файлів).
4. Видалення тек `{userappdata}\NewWin` (config, `usage.toml`, `tray_seen.toml`) і `{localappdata}\NewWin` (журнали, `taskbar-state.toml`) повністю, без запитань.

Результат: таскбар Windows показано (з тим самим автоприховуванням, що було до NewWin), від NewWin немає ні файлів, ні записів реєстру.

## 5. Полірування

### 5.1. Платформа й конфіг

- `autostart_set(false)` видаляє значення `NewWin` будь-якого типу (зараз пропускає `REG_EXPAND_SZ`).
- Під час старту shell прибирає в `%APPDATA%\NewWin` сиротливі `*.tmp` атомарного збереження, старші за 60 с. Свіжіші не чіпає, бо це може бути запис Settings, що триває.

### 5.2. Settings

- Рядки під час перетягування: автопрокрутка біля верхнього й нижнього країв списку; колесо під час перетягування перераховує слот; після перетягування мишею фокус не стрибає й список не прокручується до фокуса; переміщення з клавіатури анімоване, як мишею.
- *Custom* дата: неправильний шаблон показує в прикладі *Invalid format* / *Неправильний формат* замість порожнечі.
- Каретка текстового поля не блимає, коли вікно неактивне (і не будить таймер).
- *Clear* і *Restore Windows taskbar*: натискання одного знімає підтвердження іншого.
- `view.rs` (~870 рядків) і `body.rs` (~900) розбиваються на менші файли за обов'язками. Поведінка не змінюється.

### 5.3. Тести

- Знайти й прибрати причини нестабільності `crates/ui/tests/backdrop.rs::an_unchanged_screen_posts_nothing_more` і `tray_seen.rs::missing_file_is_empty_and_round_trip_works`. Не перезапускати їх, а виправити.
- Тести, що створюють тимчасові теки, прибирають їх за собою.

### 5.4. Прибирання після M4

- Видалити робочу теку `.superpowers/sdd/2026-10-23-newwin-m4-settings/` (у git її історія є) і `%APPDATA%\NewWin\config.backup-m4.toml`.
- README (en, uk): розділ «Встановлення» про Setup замість збірки з коду; збірка з коду лишається для розробників.

## 6. Надійність

- `--quit` ідемпотентний: повторний запуск без NewWin нічого не ламає й повертає 0.
- Інсталятор не замінює файли, поки NewWin не закрито (§2.2), тож exe не буває напівзаміненим.
- Якщо в момент видалення explorer перезапускається, `--quit` однаково показує таскбар через файл стану, як і watchdog.
- Без підпису коду SmartScreen попереджає при першому запуску Setup (дизайн §16). Це прийнято.

## 7. Тести й приймання

**Автотести:**
- `roles`: `--quit` розбирається.
- Чиста логіка `--quit` у `crates/core`: крок за кроком (попросити, чекати, добити, відновити), з таймінгами й кодом виходу.
- Watchdog не перезапускає shell, коли є подія `Quitting`.
- `autostart_set(false)` для `REG_EXPAND_SZ` (на тестовій назві значення).
- Прибирання `*.tmp`: старі видаляються, свіжі ні.
- Settings: приклад для неправильного шаблону, взаємне зняття підтверджень, слот під час колеса й автопрокрутки.

**Живий чекліст (з користувачем):**
- [ ] Setup: темний, англійською чи українською за системою, без UAC, одна сторінка з папкою; після «Готово» NewWin працює.
- [ ] Встановлення поверх запущеної збірки з `target\release`: вона закрилась, рідний таскбар з'явився лише на мить, запустився встановлений NewWin; `Run\NewWin` указує на встановлений exe.
- [ ] Перезавантаження: NewWin стартує сам.
- [ ] Spotlight знаходить *NewWin Settings*; у «Встановлених програмах» є NewWin 1.0.0 з іконкою.
- [ ] Оновлення (Setup тієї самої версії ще раз): сторінки з папкою немає, налаштування збереглися.
- [ ] *Restore Windows taskbar* у Settings: NewWin повністю вийшов і не повернувся.
- [ ] Видалення: таскбар Windows на місці; немає папки програми, `%APPDATA%\NewWin`, `%LOCALAPPDATA%\NewWin`, `Run\NewWin`, ярлика.
- [ ] Дрібниці з §5.2 наживо.
- [ ] Простій 10 хв після встановлення: CPU ≈ 0 %, RAM як у M4.

## 8. Поза межами M5

- Підпис коду, автооновлення, кілька моніторів, закріплені програми (дизайн §16).
- Встановлення для всіх користувачів у `Program Files` (потребує UAC і не дає переваг).
- Інсталятор у склі NewWin.
